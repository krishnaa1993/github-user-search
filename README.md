# GitHub User Search

A simple web app to search GitHub users and view their profile info.

## Features
- Search any GitHub username
- View profile picture, bio, followers, repos
- Save favorite users (persisted with localStorage)
- Responsive design

## Tech Stack
- HTML, CSS, JavaScript
- GitHub REST API

## How to run
1. Clone this repo
2. Open `index.html` in your browser

## What I learned
- Fetch API and async/await
- DOM manipulation
- localStorage for persisting data
- Responsive CSS with flexbox
